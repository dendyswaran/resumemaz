Practical limits

The live preview is continuous; the PDF renderer determines page boundaries. Legacy HTML keeps text and line breaks but loses inline bold/italic styling. The deferred PDF dependency is about 1.2 MB before compression and produces a large-chunk build warning. Browser QA used the available Chromium-based browser; Firefox, Safari, assistive technology, other writing systems, and forced browser-storage failure states remain unverified.

No online saving, authentication, Supabase configuration, publication, or deployment was added. Review cloud loading, offline recovery, ownership, and conflicts in the next phase.
